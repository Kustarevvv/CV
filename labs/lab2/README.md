# ЛР2. Трекинг объекта по ключевым точкам

## Теоретическая база

Объект ищется на каждом кадре методом локальных ключевых точек: детектор SIFT находит точки на эталонном кадре и на текущем кадре, дескрипторы сопоставляются через BFMatcher с тестом отношения Лоу (ratio test), по совпадениям через RANSAC считается гомография, и углы эталона проецируются на кадр через cv2.perspectiveTransform.

Для устойчивости к углу съёмки эталон дополняется синтетическими перспективными искажениями исходного кадра (аналог ASIFT) - точки с них пересчитываются обратно в систему координат эталона и добавляются в общий набор.

Если на кадре не набралось нужного числа совпадений (объект далеко, размыт или под острым углом), включается резервный режим - оптический поток Лукаса-Канаде (cv2.calcOpticalFlowPyrLK) переносит ранее найденные точки с предыдущего кадра на текущий, и гомография пересчитывается уже по ним.

## Описание разработанной системы

Код разбит на два файла в src.

tracker.py - вся логика поиска объекта: построение расширенного эталона, сопоставление по SIFT и гомографии, продолжение трекинга оптическим потоком, проверки на вырожденный результат (невыпуклый четырёхугольник, слишком малая или большая площадь, рамка далеко за границами кадра, рамка-игла с экстремальным соотношением сторон).

main.py - проход по видео: первый кадр берётся как эталон, дальше каждый кадр прогоняется через tracker.py, на найденном объекте рисуется зелёная рамка с подписью и жёлтые точки совпадений, видео сохраняется в results/videos, в конце выводится статистика по видео.

## Результаты работы и тестирования

Протестировано на четырёх видео: собственное видео (video_jl.MOV) и три видео преподавателя (mona-lisa, mona-lisa-blur, mona-lisa-blur-extra-credit).

video_jl.MOV - 517 кадров, объект найден на 100% (517 из 517), всё через гомографию, оптический поток не понадобился.

## Выводы

Связка SIFT с гомографией и оптическим потоком в резерве полностью решает задачу на собственном видео и на чистом видео преподавателя - объект не теряется ни разу. На размытом видео теряется уже заметная часть кадров, а на самом тяжёлом варианте (сильное размытие плюс отдаление) теряется треть кадров - здесь упор уже в возможности самого метода локальных признаков, а не в реализацию: на сильно смазанном мелком объекте SIFT физически не находит достаточно устойчивых точек.

Отдельно проверено, что рамка никогда не рисуется в виде вырожденного мусора (растянутая за кадр "игла") - для таких случаев добавлена отдельная проверка формы рамки, объект в этом случае честно помечается как потерянный вместо рисования неверной рамки.
